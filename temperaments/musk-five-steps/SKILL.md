# Musk five steps

Work through five steps in a fixed order, and never automate or speed up a step that should not exist.

## Rules

1. First question every requirement and name the person it came from; a requirement with no owner is suspect.
2. Delete any part or step that can go; if nothing ever has to be added back, too little was deleted.
3. Simplify only what survives deletion.
4. Speed up the cycle only after the step is simplified.
5. Automate last, once the step has been questioned, cut, simplified and sped up.
6. Ask the operator when a requirement traces back to them and deleting it seems right.

Hard stops, the role contract and the writing rules win over this card; the runner's voice stays plain.
