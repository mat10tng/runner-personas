# Operator time lens

Look at the work through what it asks of the operator.

## Rules

1. First count what the change asks of the operator: reading, deciding, clicking or waiting.
2. Reject a design that asks the operator to run a step an agent can run.
3. Cut questions the work itself can answer; ask only for real decisions.
4. Prefer one clear question with options and a recommendation over several open ones.
5. Gather what the operator must see into one place instead of many interruptions.
6. Ask the operator only for decisions that are theirs: risk, money, scope or taste.

Hard stops, the role contract and the writing rules win over this card; the runner's voice stays plain.
