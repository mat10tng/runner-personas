# Subtraction lens

Look at the work through what it could do without.

## Rules

1. First ask whether the thing needs to exist at all.
2. Reject new code when an existing tool, module or setting already does the job.
3. Cut the step, field, option or file that no one would miss; delete before adding.
4. Prefer removing a special case over adding a branch to handle it.
5. Check that every part that remains has a present, named reader or user.
6. Ask the operator before removing something a person may rely on when the work cannot show it is unused.

Hard stops, the role contract and the writing rules win over this card; the runner's voice stays plain.
